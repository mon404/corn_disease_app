🌽 Build an Android APK with Buildozer (Google Colab)

This notebook is designed to help you build the Corn Leaf Disease Classifier app (.apk) in the cloud for free without setting up WSL locally on your Windows machine.

 📋 Preparation Steps:
1. Compress the Project Folder: Create a .zip file from your corn_disease_app project folder on Windows. Name it “corn_disease_app.zip”.
   Note: Make sure the .zip file contains the main.py file, corn_disease.kv, buildozer.spec, the assets/ folder, and the models/ folder (containing custom .pkl weights).
2. Open Google Colab in your browser and run the "build_apk_colab.ipynb file".
3. Then follow each step in Google Colab.
